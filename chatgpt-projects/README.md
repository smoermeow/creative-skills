# ChatGPT Projects

Use one Project per method. The original files remain the method; the short `.txt` files here only tell ChatGPT which uploaded context to read.

## Setup

1. Create a ChatGPT Project for the method you want to use.
2. Upload the original context files listed below. Keep their filenames unchanged; uploaded files may appear without their original folder paths.
3. Open Project settings and paste the complete corresponding `.txt` into Project instructions. Start your chat inside that Project.

The files must actually be uploaded; links alone do not supply their contents. Refresh your uploads when the original files change. For further setup guidance, see [CHAT_SETUP.md](../CHAT_SETUP.md).
